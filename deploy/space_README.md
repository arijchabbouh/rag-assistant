# Assistant documentaire ENICarthage

Répond aux questions des étudiants à partir des documents officiels de l'école, en citant ses sources.
Les réponses peuvent être fausses : vérifiez l'information auprès de l'administration en cas de doute.
Ne saisissez pas de données personnelles.

Ce Space est construit à partir du dépôt du projet (voir DEPLOY.md). Ne modifiez pas ses fichiers ici :
modifiez le projet, puis relancez `python deploy/prepare_space.py` et `hf upload`.
